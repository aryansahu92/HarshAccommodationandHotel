# Harsh Accommodation and Hotel

Website starter for **Harsh Accommodation and Hotel**, Barela, Jabalpur.

## Included
- Responsive hotel landing page
- Rooms and booking enquiry interface
- Availability/date selection UI
- Facilities, gallery, offers and location sections
- Contact/WhatsApp placeholders
- Demo owner dashboard
- Browser-local booking storage
- Navy/gold hospitality branding
- No framework/build step required

## Run
Open `index.html` in a browser.

## Before production
Replace:
- `[PHONE NUMBER]`
- `[WHATSAPP NUMBER]`
- `[EMAIL ADDRESS]`
- Room prices and inventory
- Facility confirmations
- Real property photographs
- Review links
- Hotel policies

For real bookings, add a secure backend/database, authentication, server-side inventory locking, payment gateway, notifications, backups and audit logging.
